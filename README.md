# sats 가계부

비트코인 **sats** 단위로 직접 적는 수기 가계부입니다. 지갑·거래소에 연결하지 않고 수입, 지출, 이체를 손으로 기록합니다. 화면 위쪽에는 실시간 BTC 시세(원화·달러)가 표시되고, 잔액과 각 금액은 그 시세로 환산됩니다.

## 데이터

기록은 이 브라우저의 `localStorage`에만 남습니다. 서버로 전송되지 않으며, 개인키나 시드 문구를 다루지 않습니다. 브라우저 데이터를 지우면 기록도 사라지므로 설정의 JSON 백업을 받아 두세요.

## 설치

사이트: https://blackrabbit-dev.github.io/sats-ledger/

### iPhone (Safari)

1. Safari에서 위 주소를 엽니다.
2. 공유 버튼(□↑)을 누릅니다.
3. **홈 화면에 추가**를 고르고 추가합니다.
4. 홈 화면의 **sats 가계부** 아이콘으로 실행합니다.

### Android (Chrome)

1. Chrome에서 위 주소를 엽니다.
2. 메뉴(⋮)에서 **앱 설치** 또는 **홈 화면에 추가**를 선택합니다.
3. 설치한 뒤 홈 화면 아이콘으로 실행합니다.

### Mac

1. Chrome: 주소창의 설치 아이콘을 누르거나, 메뉴에서 **sats 가계부 설치**를 선택합니다.
2. Safari: 공유 버튼에서 **Dock에 추가**를 선택합니다. 그 항목이 없으면 책갈피로 두고 사용합니다.

한 번 열어 두면 서비스 워커가 앱 화면을 캐시해 오프라인에서도 기록을 보고 적을 수 있습니다. 시세 갱신에는 인터넷이 필요합니다.
